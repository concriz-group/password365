# Password365 brand

The mark: **3·6·5 forms the body of a padlock**, the 6 in orange carries the keyhole, the shackle is
steel grey. Drawn by the owner (`password365-black-orange-gray-flat.svg`, 2026-11-14) and redrawn here
as smooth vector curves with the same shapes (the original was a pixel trace).

| File | Use |
|---|---|
| `password365-logo.svg` | the mark on light backgrounds, no background |
| `password365-logo-dark.svg` | the mark on dark backgrounds (light digits, lighter steel) |
| `app-icon.svg`, `app-icon-1024.png` | app icon, light, full square (iOS masks it; extension) |
| `app-icon-dark.svg`, `app-icon-dark-1024.png` | app icon for iOS dark icons |
| `app-icon-macos.svg`, `app-icon-macos-1024.png` | desktop icon: macOS does not round icons itself, so it carries Apple's grid (824 body with rounded corners, transparent margin, soft shadow); source for `npx tauri icon` |

Colours: ink `#0D0D0D` · orange `#FF7900` · steel `#83848D` · on dark: ink `#F3F1ED`, steel `#A0A1AA`,
background `#121214`. The written name "Password365" is not part of the icon (illegible at icon sizes);
it goes beside the mark on the website, the store page and the welcome screen.

Before the store submission (M6), compare it once more with the closest password-manager and lock
icons in the App Store and Google Play.
